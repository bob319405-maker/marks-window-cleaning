# Mark's Window Cleaning — website

A redesigned, single-page website for Mark's Window Cleaning (Maidstone), built
from the content of the existing site at markrwindowcleaning.co.uk.

Plain HTML, CSS and a little JavaScript. No build step: open `index.html` in a
browser, or upload the folder to any web host.

```
index.html        page content
css/styles.css    all styling (theme colours are at the top as CSS variables)
js/main.js        mobile menu, header shadow, scroll-in animation
images/           favicon (put downloaded photos here too, see below)
```

## Photos

The photos and logo are currently loaded from the old site's image host
(`files.websitebuilder.prositehosting.co.uk`). Before closing the old website
account, save each image into `images/` and update the `src` paths in
`index.html`, otherwise they will stop showing.

## Content to check

The headings, contact details, services, areas and the "15 years" figure come
from the old site. Some paragraphs were reworded for the new layout. Please
read through the "How I work" and "About me" text (communication and weather)
and adjust it if it doesn't match how Mark works.
